Privacy policy

Last updated: 14 October 2026

Hermes is a personal, self-hosted assistant. Its only user is its owner, Tássio Noronha. This policy describes how it handles Google user data.

What data it accesses

With the owner's consent, Hermes accesses the owner's own Google account data through Google APIs: Gmail messages, Google Calendar events, and Google Drive files (including Docs and Sheets) and contacts.

How the data is used

The data is used only to perform tasks the owner asks for, such as summarising email, checking his schedule, or finding files. It is not used for advertising, profiling, or any other purpose.

Storage and sharing

OAuth tokens are stored only on the owner's own computer. Google user data is not sold, shared with, or transferred to third parties, and is not used to train models, except as needed to process a request the owner makes with a language-model provider he configured.

Google API Services User Data Policy

Hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
